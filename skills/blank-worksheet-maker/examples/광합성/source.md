# 광합성 정리 노트 (예시 자료 — 직접 작성)

광합성은 식물이 빛에너지를 이용해 이산화 탄소와 물로 포도당을 만드는 과정이다. 광합성은 잎의 세포 속 엽록체에서 일어난다. 엽록체에는 초록색 색소인 엽록소가 들어 있어 빛에너지를 흡수한다.

광합성에 필요한 물은 뿌리에서 흡수되어 물관을 통해 잎까지 이동한다. 이산화 탄소는 잎 뒷면에 많은 기공을 통해 들어온다. 기공은 두 개의 공변세포로 둘러싸여 있으며, 공변세포의 모양이 변하면서 기공이 열리고 닫힌다.

광합성으로 만들어진 포도당은 곧 녹말로 바뀌어 엽록체에 잠시 저장된다. 녹말은 밤이 되면 물에 잘 녹는 설탕으로 바뀌어 체관을 통해 식물의 여러 기관으로 운반된다. 광합성 과정에서 생긴 산소는 기공을 통해 공기 중으로 나간다.

광합성량은 빛의 세기, 이산화 탄소의 농도, 온도의 영향을 받는다. 빛의 세기가 강해질수록 광합성량은 증가하다가 어느 지점 이후에는 더 이상 증가하지 않는다. 온도는 일정 범위까지는 높을수록 광합성량이 증가하지만, 너무 높아지면 광합성량이 급격히 줄어든다.
